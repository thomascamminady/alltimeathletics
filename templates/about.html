About

A data-analysis-friendly view of every all-time performance list maintained by Peter Larsson on alltime-athletics.com.

The source data

Peter Larsson has been compiling and curating all-time top lists for track and field for decades. His site is the canonical reference for historical athletics performances on the open web. Every row served here originates from one of his event pages; this project is an unofficial wrapper that scrapes the lists weekly, parses them into a typed, columnar dataset, and serves them through tables, charts, and a browser-side SQL playground.

This project

Source code, data pipeline, schema documentation, and the issue tracker live on GitHub. The dataset is rebuilt every week from Larsson's pages and published as a dated GitHub Release — see Download for parquet, CSV, and CSV.gz snapshots, or browse all releases.

The code in this repository is released under the MIT License. The underlying performance data is © Peter Larsson — please refer to alltime-athletics.com for canonical usage terms.
